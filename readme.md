# PixelLog 🎨🎮

A retro-inspired web application for tracking, logging, and showcasing pixel art and media feeds.

## ✨ Features

* **Retro Aesthetic:** Styled with custom layouts designed for visual media logging.
* **Dynamic Feed:** Fast, responsive display powered by Node.js and Express.
* **Lightweight Backend:** Structured for fast load times and clean API routes.

---

## 🛠️ Tech Stack

* **Backend:** Node.js, Express.js
* **Frontend:** HTML5, CSS3, JavaScript
* **Hosting:** Render

## 💻 Local Setup & Development

Follow these steps to run the project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/jpldeleon/pixellog.git](https://github.com/jpldeleon/pixellog.git)
   cd pixellog

2. **Install dependencies:**
   ```bash
   npm install
  
3. **Run the application**
 ```bash
   node server.js
   ```   
4. **Open the browser:**
   Navigate to http://localhost:5000 in your web browser.
